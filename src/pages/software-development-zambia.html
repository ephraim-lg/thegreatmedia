Questions

Custom software in Zambia: common questions.

How long does it take to build custom software?+
A focused system usually takes a few weeks to a few months, depending on its size. We build in stages so you can use the first part while the rest is being finished.
Do I need an app from the app store?+
Usually not. We build web apps that open in any phone browser and can be added to the home screen, which avoids app-store delays and works on older phones.
Will it work with poor internet?+
We design for slow and unreliable connections. Where it matters, the system keeps working offline and syncs when the connection returns, as Sitolo does.
Who owns the software?+
That is agreed in writing before the build starts, so there are no surprises later.
Can you improve a system we already have?+
Often, yes. We look at what you have first and tell you honestly whether to improve it or replace it.
